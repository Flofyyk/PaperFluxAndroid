## Изменения

- Обновлено ядро Mail.ru: подключение и обработка курсорных сообщений адаптированы из актуального OpenFlux.
- Добавлена активность редактора для редактируемых документов и поддержка ссылок только для чтения без отправки правок.
- Сохранены исправления интерфейса, профили и отключение RACK/TLP для Яндекса и Mail.ru.

Для Mail.ru используйте отдельный пустой документ: активность редактора меняет его содержимое.
