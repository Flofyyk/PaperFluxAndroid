Исправлено зависание при подключении к Yandex Docs и проверке DNS/TCP.

Обработка статистики больше не блокирует чтение событий готовности туннеля во время запуска. События завершившегося native-процесса отбрасываются.

Проверено на устройстве: три последовательных подключения с подтверждением DNS/TCP и регрессионный тест блокировки.

README дополнен описанием возможностей, совместимости и ограничений.
