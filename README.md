PaperFlux Android — VPN-клиент для подключения к серверу PaperFlux через Yandex Docs. Приложение поддерживает профили подключения, исключения приложений, статистику трафика и журнал событий.

Для подключения добавьте свой профиль: отсканируйте QR-код встроенной камерой, импортируйте конфигурацию из буфера обмена или файла либо введите название, IP/домен сервера и пароль профиля. При ручном добавлении остальные параметры загружаются с сервера. Для этого владелец любого PaperFlux-сервера может установить [сервис выдачи конфигурации](https://github.com/Flofyyk/PaperFlux/blob/main/docs/PROFILES.md); без него используйте импорт полной конфигурации. Пароль профиля — ключ доступа, не SSH/root-пароль VPS.

## Возможности

- Системный Android VPN с учётом времени и трафика сессии и сохраняемым журналом событий.
- Профили: выбор, редактирование, удаление, импорт QR-кода, из буфера, файла и ручной ввод.
- Обмен профилями: QR-код, копирование ссылки и системная отправка ссылки или QR-изображения. Конфигурация содержит ключ доступа — передавайте её только доверенным получателям.
- QR-сканер работает внутри приложения, без Google Lens и Google Play Services; распознавание выполняется на устройстве, изображения не сохраняются и не отправляются.
- Исключения приложений: выбранные приложения работают в обход VPN. Изменения автоматически применяются с коротким переподключением; список сохраняется между перезапусками. Уже открытое исключённое приложение лучше перезапустить. Обход маршрутизации не скрывает системный факт наличия VPN.
- Карточки профилей с отдельной кнопкой раскрытия действий, флагом страны при успешном определении адреса и проверкой ICMP-пинга сервера. Если сервер блокирует ICMP, результат недоступен — это не доказательство отказа VPN.
- Транспорт Yandex Docs с проверкой готовности защищённого канала, автоматическим восстановлением и резервированием через два документа.
- Уведомление со статусом, счётчиками трафика и кнопкой отключения.
- Хранение секретов профиля в зашифрованном хранилище устройства.

## Устойчивость соединения

Для создания профиля доступны «Яндекс» и Mail.ru Документы. Варианты протокола Яндекса не отображаются отдельными пунктами: импортированный профиль сохраняет свой тип подключения. Тип транспорта и параметры должны совпадать с сервером PaperFlux.

Для профилей Volga используйте отдельный пустой документ: передача данных изменяет его содержимое. Старые профили не переключаются автоматически. Если Яндекс требует подтверждение доступа, приложение открывает отдельное окно проверки. Запросы документов обрабатываются последовательно, cookies собираются с начального и конечного адреса; ожидание пользователя отделено от таймаута соединения. Session не отменяет ограничения Яндекса.

Новая сборка использует Session с batched/zstd и требует совместимого обновлённого сервера. Внутренняя совместимость с cookies и служебной авторизацией сохранена; служебный канал не передаёт обычный VPN-трафик. [Настройка сервера](https://github.com/Flofyyk/PaperFlux/blob/main/docs/TRANSPORTS.md).

Профиль может использовать один или два документа Yandex Docs. При двух документах независимые TCP-потоки распределяются между доступными каналами. Если один канал временно закрывается со стороны сервиса, работающий канал продолжает передавать трафик, а закрывшийся подключается заново в фоне. Статус подключения подтверждается только после проверки защищённой сессии и прохождения DNS/TCP через сервер.

Краткий обрыв не требует пересоздания VPN-интерфейса: после возвращения канала сразу выполняется новая DNS/TCP-проверка. Если сервер перезапущен, клиент повторно подтверждает его через свежий криптографический challenge. При отсутствии сети приложение ожидает её возвращения; ручное отключение отменяет восстановление. Повторный запуск сервиса сохраняет foreground-уведомление.

## Требования

### Авторезерв серверов

Версия 0.4.16 поддерживает наборы `paperflux://pool?data=…` из 2–8 уже настроенных VPS. Импорт — через буфер, файл или встроенный QR; обмен экспортирует весь набор. Каждый узел содержит отдельный полный конфиг. Карточка показывает число серверов, а ключи всех узлов остаются в зашифрованном хранилище, не передаются в WebView.

Рабочий сервер остаётся выбранным. При полном отказе защищённого канала приложение может перейти на резервный, временно исключая неисправный узел. Ротация одного документа не переключает VPS; отсутствие интернета и ожидание CAPTCHA не считаются отказом сервера. Переключение выполняется только при включённом автореконнекте.

При восстановлении набора приложение удерживает VPN-интерфейс, пока есть интернет и не требуется подтверждение доступа. При смене VPS открытые TCP-соединения восстанавливаются заново, возможны пауза и смена внешнего IP. Набор не является автообновляемой подпиской и не устанавливает серверную часть. [Формат и требования к узлам](https://github.com/Flofyyk/PaperFlux/blob/main/docs/MULTIUSER.md).

- Android 8.0 или новее.
- Одна из архитектур: `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`.
- Совместимый сервер PaperFlux и действующий профиль подключения.

Android 0.4.16 использует Session и совместим с PaperFlux Server 0.5.6–0.5.8. Для исправления накопления старых соединений после переподключения в групповом proxy обновите сервер до 0.5.8. Предыдущий PFS2-режим не совместим с Session. Для добавления по адресу и ключу включите сервис конфигурации на сервере; для импорта полной конфигурации он не требуется.

## Какой APK выбрать

- `universal` — содержит все четыре архитектуры; выбирайте, если не знаете тип процессора.
- `arm64-v8a` — большинство современных телефонов.
- `armeabi-v7a` — устройства с 32-битной Android на ARM.
- `x86` и `x86_64` — устройства и эмуляторы с процессором Intel/AMD.

Функции одинаковые; отдельный APK занимает меньше места. Работа на реальном телефоне проверена для ARM64; остальные архитектуры прошли сборку и проверку упаковки, но не проверены на отдельных устройствах.

## Установка и подключение

1. Скачайте APK из [последнего релиза](https://github.com/Flofyyk/PaperFluxAndroid/releases/latest) и установите приложение.
2. Откройте «Профили» и добавьте конфигурацию по QR-коду, из буфера, файла или вручную.
3. Выберите профиль и нажмите кнопку подключения на главном экране.
4. При первом запуске разрешите создание VPN-соединения в системном диалоге Android.

Чтобы направить отдельные приложения в обход VPN, выберите их в «Настройки → Исключения приложений». Сервис применит список автоматически. После применения перезапустите исключённое приложение, если оно сохраняет старые соединения.

Исходный код серверной части находится в [PaperFlux Server](https://github.com/Flofyyk/PaperFlux). Проект основан на [p1neappleXpress/OpenFlux](https://github.com/p1neappleXpress/OpenFlux); PaperFlux Android поддерживается как отдельный клиент.

## Сборка из исходников

Нужны Android SDK 35, JDK 17 или новее и Node.js 20.19+ либо 22.12+. Исходники интерфейса находятся в `web/`; Gradle устанавливает зависимости по lock-файлу и собирает интерфейс. Native-бинарники для четырёх ABI включены в репозиторий. Для их пересборки нужны Go 1.26.4+ и Android NDK 27.0.12077973+; используйте `scripts/build-android-native.ps1` в серверном репозитории.

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-universal-debug.apk
```
