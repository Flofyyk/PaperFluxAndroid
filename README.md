PaperFlux Android подключает приложения к серверу PaperFlux через зашифрованный документный транспорт. Для работы требуется настроенный сервер и профиль доступа.

[Версия 0.4.30](https://github.com/Flofyyk/PaperFluxAndroid/releases/tag/v0.4.30) исправляет резервный DNS, ожидание и очередь проверок Яндекса, а также восстановление зависших соединений Mail.ru. В журнале доступны причины ошибок DNS/TCP. Включено ядро `0.5.17`; режим локального SOCKS5 и выбор приложений для VPN сохранены.

## Возможности

- Профили подключения с редактированием, диагностикой и обменом конфигурациями.
- Импорт по QR-коду, из буфера обмена, файла или по адресу сервера и ключу доступа.
- Встроенный QR-сканер без Google Lens и Google Play Services.
- Режимы VPN и локального SOCKS5 без системного VPN-интерфейса.
- Исключение приложений или VPN только для выбранных приложений.
- Резервирование через два документа Яндекса и дополнительный канал Volga.
- Автоматическое восстановление соединения и поддержка наборов резервных VPS.
- Статистика трафика, задержка соединения и журнал событий.
- Уведомление со статусом VPN и кнопкой отключения.
- Плитка в шторке для подключения и отключения выбранного профиля.
- Проверка обновлений с GitHub, загрузка APK и напоминание с отсрочкой на 24 часа.
- Зашифрованное хранение ключей профилей.

## Требования

- Android 8.0 или новее.
- ARM64, ARMv7, x86 или x86_64.
- Сервер PaperFlux с протоколом Session и действующая конфигурация.

## Установка

Скачайте APK из [последнего релиза](https://github.com/Flofyyk/PaperFluxAndroid/releases/latest).

| APK | Назначение |
| --- | --- |
| `universal` | Все поддерживаемые архитектуры |
| `arm64-v8a` | 64-битные ARM-устройства |
| `armeabi-v7a` | 32-битные ARM-устройства |
| `x86` / `x86_64` | Устройства и эмуляторы Intel/AMD |

Если архитектура неизвестна, используйте `universal`.

1. Установите APK и откройте приложение.
2. Добавьте конфигурацию на вкладке «Профили».
3. Выберите профиль и нажмите кнопку подключения.
4. В режиме VPN разрешите создание VPN-соединения в системном диалоге Android.

## VPN или прокси

В «Настройки → Режим подключения» выберите VPN или Прокси. Перед сменой режима отключите PaperFlux.

VPN создаёт системный туннель. Прокси не создаёт VPN-интерфейс и слушает только `127.0.0.1:1080`. Укажите в нужном приложении SOCKS5, адрес `127.0.0.1`, порт `1080`, без логина и пароля. Только настроенные на прокси приложения используют документный канал; остальной трафик не перехватывается PaperFlux.

Поддерживаются TCP и доменные имена с DNS через канал; UDP и IPv6 пока не поддерживаются. Если другое приложение создаёт VPN и использует PaperFlux как прокси, исключите PaperFlux из его VPN, иначе возможна петля подключения. Работа связки с InviZible/Tor на реальном телефоне ещё не проверена.

## Настройка профиля

Полную конфигурацию можно импортировать из ссылки `paperflux://`, файла или QR-кода. Для обмена доступны копирование ссылки и отправка QR-изображения через системное меню Android.

При добавлении по адресу сервера указываются название, IP/домен и пароль профиля. Остальные параметры загружаются через [сервис выдачи конфигурации](https://github.com/Flofyyk/PaperFlux/blob/main/docs/PROFILES.md). Если сервис не настроен, используйте импорт полной конфигурации.

Пароль профиля — ключ доступа к PaperFlux, не SSH-пароль VPS. Ссылка и QR содержат этот ключ: передавайте их только доверенным получателям.

## Транспорты и восстановление

Поддерживаются Яндекс и Mail.ru Документы. Для Volga нужен отдельный пустой документ с правом редактирования: транспорт изменяет его содержимое. При необходимости подтверждения доступа к Яндексу приложение открывает окно проверки.

Для Mail.ru тоже используйте отдельный пустой документ: при наличии права редактирования отправляются периодические правки редактора. Ссылки только для чтения принимаются без отправки правок; доступность соединения зависит от сервиса.

Окно проверки указывает документ и сторону подключения — телефон или VPS. Передача результата не означает, что туннель уже готов: приложение отдельно проверяет доступ к документам и DNS/TCP.

Cookies проверки сохраняются между подключениями с телефона и не заменяются фоновым ответом VPS. В журнале передача результата отмечается отдельно для каждого документа; прежние предупреждения остаются историей событий, а не текущим статусом VPN.

Если проверка нужна для подключения, окно открывается автоматически в видимом приложении. Повторные запросы одного канала не создают серию окон. При уже работающем VPN проверки дополнительных каналов не перекрывают экран; открыть их можно из уведомления. Если Яндекс показывает CAPTCHA, её нужно пройти вручную — приложение автоматически передаст результат после подтверждения.

Статус «Подключено» появляется после установления защищённой сессии и проверки DNS/TCP. Недоступный документ восстанавливается в фоне; при отсутствии сети приложение ожидает её возвращения. Ручное отключение отменяет восстановление.

При включённом автореконнекте VPN-интерфейс сохраняется во время автоматического восстановления и ожидания сети, включая одиночные профили. Ручная остановка закрывает его. Принудительное завершение приложения или отзыв VPN-разрешения ОС этим механизмом не защищаются; исключения приложений остаются прямым выходом в сеть.

Если конфигурация требует активации (`activationRequired`), приложение обращается к сервису выдачи на TCP 24000 до старта туннеля. Для неё нужны совместимый менеджер и прямая доступность сервера; в сети с белым списком используйте обычный заранее запущенный профиль.

Наборы резервных серверов содержат отдельные конфигурации уже настроенных VPS. Переключение доступно при включённом автореконнекте; смена VPS требует повторного установления открытых TCP-соединений.

## Выбор приложений для VPN

В «Настройки → Приложения и VPN» доступны режимы «Все, кроме выбранных» и «Только выбранные через VPN». Списки сохраняются отдельно и автоматически применяются с коротким переподключением VPN. Для режима включений выберите хотя бы одно установленное приложение. Если приложение сохраняет старые соединения после смены списка, перезапустите его. Эти настройки не действуют в режиме прокси.

Исключения направляют трафик в обход туннеля, но не скрывают системный признак наличия VPN.

## Настройки и обновления

DNS и MTU сохраняются после перезапуска приложения. Изменения применяются при следующем подключении VPN; DNS документного транспорта остаётся отдельным от DNS приложений внутри туннеля.

Запуск следующей сессии ждёт завершения остановки предыдущей, без дополнительной паузы.

Плитка PaperFlux доступна в системном редакторе шторки. Перенесите её в активные плитки вручную; отдельная кнопка в приложении не требуется.

Приложение проверяет стабильные релизы GitHub при открытии. В окне обновления выберите «Обновить» для загрузки APK или «Пропустить», чтобы отложить напоминание на 24 часа. APK проверяется перед установкой; установку подтверждает Android. Проверка вручную доступна в настройках. Для проверки и загрузки нужен доступ к GitHub.

## Сборка

Требуются Android SDK 35, JDK 17+ и Node.js 20.19+ или 22.12+.

```bash
./gradlew :app:assembleDebug
```

APK находятся в `app/build/outputs/apk/debug/`. На Windows используйте `gradlew.bat`.

Исходники интерфейса находятся в `web/`; Gradle устанавливает зависимости по lock-файлу и собирает интерфейс автоматически. Native-ядро включено для всех четырёх ABI. Для его пересборки нужны Go 1.26.4+, Android NDK 27.0.12077973+ и [build-android-native.ps1](https://github.com/Flofyyk/PaperFlux/blob/main/scripts/build-android-native.ps1).
